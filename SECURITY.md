# Política de segurança

## Versões suportadas

Somente a versão mais recente da branch `main` recebe correções de segurança.

## Relatando uma vulnerabilidade

Não abra uma issue pública.

Use **Report a vulnerability** na aba **Security** do repositório para enviar
um relato privado. Se esse recurso ainda não estiver disponível, contate o
mantenedor pelo perfil indicado no README e peça um canal privado sem revelar
os detalhes no primeiro contato.

Inclua, quando possível:

- descrição e impacto;
- passos mínimos para reproduzir;
- versão ou commit afetado;
- sugestão de correção.

Não envie tokens reais, dados pessoais ou testes que afetem serviços de
terceiros. O mantenedor confirmará o recebimento e coordenará a divulgação da
correção pelo mesmo canal privado.
